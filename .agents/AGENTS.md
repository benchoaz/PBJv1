# Complex Debugging Guidelines

Untuk debugging yang lebih kompleks (misalnya aplikasi web, API, atau sistem produksi), gunakan metode berikut:
- Reproduce Issue
- Log Analysis
- Root Cause Analysis (5 Whys)
- Dependency Check
- Configuration Review
- Performance Review
- Security Review

Jika terdapat beberapa kemungkinan penyebab, berikan tingkat keyakinan (%) untuk masing-masing.
